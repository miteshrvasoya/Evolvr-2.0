## First Vertical Slice (Milestone 1)

The absolute first working milestone proves the closed loop works before any real API:

```
Goal (configured in dashboard)
  → Strategy (generated by Strategy Agent)
  → Content Idea (generated by Content Agent)
  → Quality Check (PolicyEngine)
  → Simulated Publish (SimulatedInstagramAdapter)
  → Simulated Analytics (+24h simulated metrics)
  → Learning (insight recorded)
  → Revised Strategy (if evidence threshold met)
```

This runs entirely in `SIMULATION_MODE=true` and validates the entire agent architecture before connecting a real Instagram account.
